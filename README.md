# GTA VI trophy rarity forecast

[Forecast how many GTA VI players earn each trophy in week one](https://make.fun/bounty/gta6-trophy-rarity-forecast-01)

This program forecasts every GTA VI PS5 trophy's Exophase earn rate a week after launch, as five quantiles per trophy, from the house's recorded reads of the trophy page.

Run it with `python3 main.py`, reading cases from `$MAKEFUN_INPUT_DIR` (default `/input`) and writing forecasts to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
